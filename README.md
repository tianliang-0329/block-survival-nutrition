# 合理膳食 · 游戏大厅

[扫码入口与在线试玩](https://tianliang-0329.github.io/block-survival-nutrition/)

- **方块突围 V6.5.1**（action-demo.html）：即时动作，收集食材并搭配餐盘。手机竖屏时自动将游戏画面转成横向，系统开启方向锁定也可直接开始。战场铺满手机可视区域，摇杆与攻击按钮叠在画面两侧。左手拖动摇杆，右手点按或按住攻击。电脑 WASD 或方向键移动，鼠标射箭，空格冲刺，C 工作台，U 强化。经验攒满时自动弹出强化，稍后可从强化按钮打开。首个首领与末影龙登场前会提示关键破盾操作。
- **方块食堂 V2.2**（games/card/index.html）：膳食卡牌。打出食材推进战斗，搭配食材可自动合成配方。每站有一次食品安全备餐选择，游戏内有五大要点的复习手册。首次点击开局或「播放音乐」会开启原创配乐。对应源码、构建配置与许可文件位于 games/card。

双击 index.html 可以离线进入两款游戏。也可运行 node scripts/serve.mjs。运行 node scripts/build.mjs 生成 dist/index.html 和站点文件，之后可用 node scripts/test-v6.mjs 执行 Edge 浏览器回归测试。

方块突围素材来源见 ASSETS-LICENSES.md 与 assets/minecraft/sources.json。卡牌游戏的素材说明可在游戏内查看。配乐见 AUDIO.md。
